# Korça Raporton 3D

Platformë qytetare në shqip ku banorët raportojnë probleme të Korçës mbi një hartë interaktive 3D.

## Features

- Hartë 3D me ndërtesa, rrugë, zona të gjelbra dhe pika raportimi
- Rrotullim, zhvendosje dhe zoom me maus
- Regjistrim dhe hyrje me email dhe fjalëkalim përmes Supabase Auth
- Formular me kategori, foto, përshkrim, urgjencë dhe vendndodhje
- Raportime të ruajtura në Supabase Database
- Kërkim, filtra, renditje, votim dhe statistika
- Dizajn responsive për kompjuter dhe telefon

## Konfigurimi i Supabase

1. Hap Supabase dhe shko te **SQL Editor**.
2. Ekzekuto përmbajtjen e `supabase_setup.sql`.
3. Aktivizo Email provider te **Authentication → Providers → Email**.
4. Për testim, mund të çaktivizosh përkohësisht konfirmimin e email-it.

## Publikimi

Projekti është një faqe statike. Hap `index.html` në shfletues ose publikoje në Vercel/GitHub Pages.

## Teknologjitë

HTML, CSS, JavaScript, Three.js, OpenStreetMap dhe Supabase.

Ndihma nga AI është përdorur për ideimin, disa pjesë të kodit dhe përmirësimet e ndërfaqes. Kodi është përshtatur dhe testuar për këtë projekt.
